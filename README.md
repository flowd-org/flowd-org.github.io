## About

flowd.org Project Website

FLOWD stands for **Framework for Language-agnostic Orchestration of Workflows Distributed**. This site documents `flwd`, the reference implementation of that framework.

### Naming note

This project is **not related to “flowd”, the NetFlow collector by Damien Miller**. The engine and CLI are called `flwd`; `flowd.org` and this repository name are acronym-based URLs for FLOWD. All documentation keeps `flwd` clearly distinct from the existing `flowd` NetFlow daemon so both can safely coexist on the same systems.
